## How I approach frontend work

1. Understand the user journey and the design before choosing an implementation.
2. Use semantic HTML and accessible interaction patterns as the starting point.
3. Keep state, components and styling understandable for the next developer.
4. Test important behaviours, loading states and edge cases, not just the happy path.
